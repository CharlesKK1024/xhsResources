端接口设计 (FastAPI + aiosqlite)
在 source/web/__init__.py 中新增以下两个接口：
接口 1：获取/保存用户配置
路径：/web/api/user/config
方法：GET (获取) / POST (保存)
GET 逻辑：SELECT nickname, avatar_url, theme, is_login FROM user_config WHERE id = 1，返回 JSON。
POST 逻辑：接收前端传来的 JSON，执行 UPDATE user_config SET nickname=?, avatar_url=?, theme=?, is_login=1, updated_at=? WHERE id = 1。
接口 2：头像上传
路径：/web/api/user/avatar
方法：POST
参数：FormData (file: UploadFile)
逻辑：
检查并创建 Cache/Avatars/ 目录。
将接收到的图片文件异步写入该目录（建议用时间戳重命名防止重名）。
返回图片的访问路径（如 /cache/avatars/xxx.jpg，需确保 FastAPI 挂载了 Cache 目录的静态文件服务）。
4. 前端 UI/UX 交互设计
A. 登录/初始化弹窗 (Modal)
触发时机：页面加载 (DOMContentLoaded) 时，调用 GET /web/api/user/config。如果返回的 is_login 为 0 或获取失败，则弹出全屏遮罩层。
界面元素：
头像区域：点击触发 <input type="file">，选择图片后先调用上传接口获取 URL，并实时预览。
昵称输入框：绑定 nickname。
主题切换：Switch 开关，实时切换页面 data-theme 属性并绑定 theme 变量。
确认按钮：点击后调用 POST /web/api/user/config 保存，成功后关闭弹窗。
B. 主界面展示
位置：固定在页面左上角或右上角。
展示：从接口获取 avatar_url 和 nickname 进行渲染。
编辑：点击头像区域可再次唤起配置弹窗（此时弹窗标题变为“个人设置”）。
C. 深色/白天模式适配
初始化：页面加载获取配置后，立即执行 document.documentElement.setAttribute('data-theme', theme)。
切换：前端 Switch 开关 change 事件触发时，同步更新 DOM 属性和待保存的 theme 变量。
5. 开发实现步骤（给编辑器的指令）
数据库迁移：在 source/module/recorder.py 的初始化方法中，加入创建 user_config 表的 SQL 逻辑，确保程序启动时表结构存在。
后端接口实现：
